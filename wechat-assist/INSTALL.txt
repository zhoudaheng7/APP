知会 · 微信 AI 助手 0.1.0

一、在 iPhone 安装

1. 下载 WeChatAssist-0.1.0-unsigned.ipa。
2. 使用你已有的自签工具导入该文件，按该工具的流程签名并安装。
3. 签名时保留 App 的本地网络访问能力。此 App 最低要求 iOS 17.0。
4. 这是待自签的真机安装包，不能直接当作已签名 App 安装。无需把 Apple ID 密码、证书私钥或证书密码发到聊天里。

二、启动 Windows 助手

1. 解压「知会-微信AI助手-首版工程.zip」，进入 WeChatAssist 文件夹。
2. 双击 Start-Windows.cmd。保留打开的运行窗口。
3. 浏览器会打开电脑工作台。
4. 在「配置 AI」中填写你自己的兼容模型 API 基础地址、模型名称和密钥。密钥仅保存在当前 Windows 服务进程内；重启服务后重新配置。

三、选定要辅助的聊天

1. 在 Windows 微信进入目标聊天，并保持窗口可见。
2. 工作台点「选择聊天区域」：先圈选顶部聊天名称的文字，再圈选消息内容区域。
3. 第二次框选应避开左侧联系人、聊天标题和底部输入框。
4. 点「开始读取」后切回目标微信聊天。保持微信在前台，位置和大小不变。
5. 开启「自动生成候选回复」后，选区识别内容变化时会请求你配置的模型。

四、配对 iPhone

1. iPhone 与 Windows 电脑连接同一局域网。
2. 电脑工作台点「iPhone 配对」，复制整段配对信息，仅传到你自己的 iPhone。
3. 打开 iPhone「知会」，粘贴配对信息并点「连接 Windows」。首次连接按系统提示允许本地网络访问。
4. 如果电脑有多个网络地址，请选与手机同一网段的地址。电脑防火墙或网络隔离可能阻止连接，需要按本机实际情况允许局域网通信；不要做公网端口映射。
5. Windows 服务重启后，旧配对会失效，需要重新复制配对信息。

五、生成和发送回复

1. 手机「上下文」查看当前文字识别结果，核对内容。
2. 「回复助手」查看解释、生成候选、选择并编辑话术。
3. 复制回复后，回微信核对联系人并自行发送。
4. 电脑工作台也可执行同样的 AI 分析和编辑。切到工作台时屏幕读取会暂停，可手动分析最近一次上下文；回到微信后恢复读取。

首版边界

• Windows 负责识别可见聊天文字；没有读取 iPhone 微信数据库，也不会遍历全部聊天历史。
• 不转写语音、不解析图片；OCR 可能出现错字、缺字或说话人不明，需要核对。
• 切换聊天、窗口移动或微信失去前台时暂停；这不是后台全量消息监听。
• Windows 在线时可以持续自动生成。iPhone App 打开时同步；手机进入后台或锁屏后不保证刷新。
• 云端编译和 IPA 格式检查成功不等于真机运行已验证。签名安装、iPhone 配对、真实微信连续识别和真实模型仍需要实际联调。

工程详细说明见 WeChatAssist/README.md。

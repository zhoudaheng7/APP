# 一甩 0.3.0 · iPhone 原生测试版

真实实现：iPhone 之间上下左右甩送照片、视频和普通文件；原文件不压缩/不转码，收到后按字节数及 SHA-256 核验。单次一个非空文件，最大 2 GiB。选择器使用当前编码偏好；原文件指来源交给 App 的文件，Live Photo 伴随视频尚不作为整套资源发送。

新增原生功能：6 组发送/接收音效及静音，双方独立设置，音量与试听、触感开关；6 个 App 图标可通过系统备用图标 API 切换；设备间好友申请须双方确认，可移除、屏蔽和解除；默认每次接收先确认，好友可以主动开启前台自动展开。声音为测试合成音效与普通中文合成语音，不是现成动漫人物录音。

接收前只展示发送者、文件名和大小。确认后再展开预览，开始传原文件；预览缩略图单独压缩，原文件保持选定字节。发送或接收拒绝/取消/超时不显示成功。接收者必须在接收页，已打开的内容需先收起才能接下一个。

陌生人必须实测确认在 20 米内；NI 距离未知/无效/过期就不认为在范围内。可手动核验的发现设备单独标为距离未确认，不伪装成 20 米附近列表。双方也可核对连接码后明确加为本地好友，好友不受陌生人附近分享门限限制。超宽带有硬件、权限、朝向和视场限制，数据 3 秒过期；不可用时显示未确认，绝不编造距离。

Wi-Fi、蓝牙开关开启，无需路由器或互联网，实际点对点链路由系统选择。连接使用加密 MC 会话及 P256 随机挑战验证已配对身份。本地好友、发现、接收、自动重连、屏蔽均可管理。关闭发现会停止新设备广播和浏览，现有会话可继续。

UI 使用 SwiftUI 原生 Liquid Glass、导航、标签栏、玻璃按钮和系统 PhotosPicker。iOS 最低 26。支持动态字体、减弱动态效果和替代发送按钮。

系统照片/文件 → 分享 → 一甩可在独立分享扩展甩送；主 App 内选中内容即打开甩送页，不加入主页。分享扩展无强制 App Groups 签名能力，配对、好友和音效独立；第一次从扩展发起需重新核对/添加好友。接收方使用主 App 接收页。保持扩展窗口打开直到已送达。

尚未实现：远程服务、云账号通讯录、聊天与后台推送，Android/HarmonyOS 客户端及其真实互传。这些在上一轮仅是交互模拟，本 IPA 的设置页明确标记未接入，不伪造连接或送达。iOS 近场通道后台断开，不能强制解锁/弹图，未使用音频/定位保活。声音遵循系统静音和媒体音量，`.ambient` 不打断其他音频。

## 构建与签名

macOS / Xcode 26+：`brew install xcodegen`，`swift test`，`xcodegen generate` 后：

```sh
xcodebuild build -project Flick.xcodeproj -scheme Flick -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath build/device CODE_SIGNING_ALLOWED=NO
python3 scripts/package_ipa.py build/device/Build/Products/Release-iphoneos/Flick.app output/Flick-0.3.0-unsigned.ipa
```

未签名 IPA 包含真实 arm64 iPhoneOS 主程序和分享扩展，用户用手机已有证书分别重签。必须保留并签名 Share.appex、音效和备用图标资源。不得把证书私钥传至公开仓库。两台必须同时更新 v0.3（协议 3，v0.2 不兼容）。

首次测试：双方开启 Wi-Fi/蓝牙/本地网络 → 核对码连接 → 若 UWB 不可测，双方在好友页确认申请 → 接收方切接收页 → 发送方选中照片四向甩送 → 接收方确认 → 检查原文件核验 → 声音/图标/视频/文件/分享扩展逐项验收。

规则单测和设备 SDK 编译不等于两台真机验收。iPhone 17 Pro Max / 16 Pro Max、iOS 27.0.1 的无线链路、签名工具、UWB、分享扩展、静音和图标切换仍需实机验证。

# 声屿 0.4.1 设备检查

建议同应用身份覆盖安装，保留原录音。

1. 仅内部音：戴耳机播放，旁边讲话；停止后应只保留内部声音。
2. 内部音＋麦克风：授权后播放并讲话，检查同一M4A中的两路声音；外放可能重复收音。
3. 分别检查App、快捷指令和控制中心入口。App/快捷入口用录音实时活动停止；控制中心录音用系统停止。
4. 首次试听、中间定位后试听，时钟和波形游标都应自动前进；暂停保持位置。
5. 检查时长、大小、音轨、仅音频导出。合并生成新录音并保留原件；删除记录时其音频与附属JSON一起移除。
6. 检查锁屏、耳机/蓝牙、5分钟及30分钟以上录音，记录实际机型与系统版本。

云端检查不能代替设备音源、签名权限和后台表现验收。

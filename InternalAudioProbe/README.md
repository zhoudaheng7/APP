# 声屿 0.4.3

iPhone 纯音频录音，支持 iOS 27 及以上。

- 仅内部音，或内部音＋麦克风，保存为 M4A。
- 连续录音，不按分钟切段，不保存画面。
- 文件按开始时间命名，例如 `2026-10-20_13-16-00.m4a`。
- 波形试听、拖动定位、时长和文件大小。
- 合并录音、单条或多选删除，仅导出音频。
- 支持控制中心、快捷指令及录音实时活动。
- 开始、结束录音提供震动反馈，实际效果受系统设置及后台状态影响。

## 使用

选择模式，点“开始内录”，确认系统授权后切到播放 App。停止后在录音记录中试听或导出。

控制中心：长按“录屏”选择“声屿 · 仅音频”。需要签名服务正确启用共享存储；混音时开启系统麦克风开关，从系统录屏按钮停止。

快捷指令：搜索“声屿”，选择“录音菜单”“仅内部音”或“内部音＋麦克风”。

App 或快捷入口开录后，可长按灵动岛展开并停止，也可从锁屏录音活动停止。

## 安装与构建

企业签名配置见 SIGNING.md。应用身份保持兼容，建议覆盖安装保留录音。

GitHub Actions 使用 Xcode 27 构建设备 IPA；音频核心检查与模拟器界面检查分别运行。授权、音源和后台表现仍需设备验证。
